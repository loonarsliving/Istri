# analyses/

Satu folder per analisis: `analyses/<YYYY-MM-DD>-<slug>/`. Dibuat oleh skill
(`/business-feasibility`, `/loonars-board`, …). Isi umum:

```
idea.md  board/  board.md  market.md  competitors.csv  customer.json  pitch.md
panel/  pricing-curve.md  inputs/  hospitality.md  investment.md  risks.md
worst-case.md  alternatives.md  feasibility.md
```

Repo publik: input berisi angka aktual atau data pribadi disimpan di
`private/analyses/<slug>/` dan dirujuk dari sini.
